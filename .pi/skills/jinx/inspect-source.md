# Find a package's source tree

Use when you need to locate the source tree a recipe builds.

## Where a package's source lives

| What | Where |
|---|---|
| Build tree (`source_dir`); fetch target, overwritten by `jinx regen` from `-workdir` | `distro/sources/<name>` (normal) or `distro/host-sources/<name>` (host) |
| Diff base for `jinx regen`: upstream source **plus the official patches** (never the working patch); regenerated by prepare; not hand-edited | `distro/sources/<name>-clean` (normal) or `distro/host-sources/<name>-clean` (host) |
| Editable working copy (upstream + official + working patches); what `jinx regen` diffs | `distro/sources/<name>-workdir` |
| Patches | `distro/recipes/<name>/patches/` |

jinx's `JINX_SOURCE_DIR` is `distro/`, so sources and workdirs live under `distro/sources/`. To get
the exact path from inside the environment: `jinx run-in <name> bash` then `echo $source_dir`.
